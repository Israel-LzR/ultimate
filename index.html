Adopi

Sitio web para adoptar mascotas · Proyecto escolar, Unidad 3 – Saber Hacer

Nota: Adopi es una aplicación con servidor (ASP.NET Core) y base de datos (SQL Server), por eso no puede ejecutarse dentro de GitHub Pages, que solo sirve páginas estáticas. Esta página resume el proyecto; la versión funcionando se muestra en la exposición.

¿Qué hace?

  • Muestra animales en adopción con filtros y fotos.
  • Cuestionario de 8 preguntas que indica si la persona es apta para adoptar.
  • Envío de solicitudes de adopción (requiere iniciar sesión).
  • Donaciones simuladas que suman al fondo del refugio.
  • Panel de administración: alta, edición y baja de animales, revisión de solicitudes y donaciones.

Tecnologías

ParteTecnología
ServidorASP.NET Core MVC y API (.NET 10)
Base de datosSQL Server con Entity Framework Core (6 tablas relacionadas)
ClienteHTML, CSS y JavaScript (fetch)
SeguridadSesiones, roles, contraseñas con hash PBKDF2, HTTPS

Arquitectura en capas

Botón → JavaScript (fetch) → Controlador API → Servicio (reglas) → Repositorio (EF Core) → SQL Server
  • Dominio: entidades, enums e interfaces.
  • Aplicacion: servicios con las reglas de negocio.
  • Infraestructura: DbContext y repositorios.
  • AdopcionWeb: controladores, vistas y JavaScript.
